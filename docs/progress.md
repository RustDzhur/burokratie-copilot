## Текущая задача: сканер, фото-страницы, распределение документов (запрос владельца 2026-10-15)

Жалобы владельца: (1) сканер спрятан в меню, с телефона быстро сфотографировать нельзя; (2) две фотографии не собираются в один PDF,
идут как два файла, после подтверждения исчезают; (3) документы сортируются по вкладкам неверно: в «Семья, учёба, здоровье» попали
бизнес-план и документ о перерегистрации фирмы, в «Финансы» — формуляр Gewerbe, заключение медицинской комиссии на ребёнка — в «Договоры».

### Найденные причины (проверено запуском локального стека)
1. **Фото (JPEG/PNG) вообще не читаются.** `TextExtractionService` не имеет извлекателя для `image/*`, шаг TEXT_EXTRACT пропускается
   («No text extractor handles the content type image/jpeg»), OCR не запускается, текста нет. Классификация по тексту невозможна.
2. **Панель «что происходит с документом» отвечает 500** для любого классифицированного документа: SQL в
   `DocumentOutcomeController.matchedPassages` ссылался на `d` до его `join`. Исправлено (`DocumentPanelIT`).
3. Подтверждение проверки (`ReviewService`) применяет *предложенный* тип; если предложение неверно, человек, нажавший «подтвердить»,
   закрепляет ошибку. Выбора типа на экране проверки нет.
4. В таксономии нет бизнес-категории и типов для бизнес-плана, Gewerbe-формуляров, медицинских заключений комиссий.

### План по шагам (✔ сделано, ▶ в работе, ☐ впереди)
- ✔ S0 Панель документа: 500 исправлен, тест `DocumentPanelIT`.
- ✔ S1 Фото: `ImageTextExtractor` → OCR (серый, масштаб, контраст, повороты 90/180/270 при слабом чтении), `PhotoOcrIT` (прямое, на боку, вверх ногами — читаются и распознаются как счёт); tesseract в CI.
- ✔ S2 Сканер: кнопка «Scannen» (📷) на каждом экране открывает панель съёмки на месте (`QuickCapture`, `CapturePanel`); страницы по
  умолчанию собираются в ОДИН PDF (порядок, удаление, «каждая страница отдельно» по желанию); после сохранения видно чтение, найденный
  тип и ссылки «открыть документ» / «к проверке»; в верхней панели ссылка «N документов к проверке» (`Topbar`).
- ☐ S3 Распределение: новые типы и правила (бизнес, Gewerbe, медицина/комиссии), вкладка «Бизнес», классификатор с границами слов,
  весом заголовка и отрывом от второго места; иноязычный документ — на проверку, а не в случайный тип; экран проверки с явным выбором
  типа; расширенный набор оценки с примерами владельца.
- ✔ S4 Причина «исчезновения»: списки документов, задач, договоров и дел шли от старых к новым без выбранной сортировки — новый документ
  оказывался на последней странице. Теперь новые первыми (`DocumentListOrderIT`); `GET /documents/{id}` теперь называет тип.
- ☐ S5 Сквозной прогон на локальном стеке (фото двух страниц → один PDF → тип → вкладка), запись результата сюда.
