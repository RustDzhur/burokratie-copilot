## The three addresses, in every language

| Item | Address |
|---|---|
| Copilot in the cloud | `https://burokratie.firmspace.de` (API: `https://burokratie.firmspace.de/api/v1`) |
| Robot cabinet | `https://agents.firmspace.de` |
| Runtime on-premises | the address printed by the installer, e.g. `http://192.168.1.20:8080` (API: `<url>/api/v1`) |

The three tokens are **not** interchangeable: the Copilot API token, the bridge token and the
Runtime admin token come from three different places. Each language's `README.md` links to a
diagram and the exact steps.

> Older links to `docs/deployment/RUNTIME.md` etc. are kept as short forwarding pages, so
> existing scripts and tickets continue to work.
