## Как составлена и что здесь НЕ проверялось

- Каждая строка опирается на файлы, классы и тесты, которые существуют в дереве. Скрипт сборки этой матрицы проверяет, что **каждый указанный в колонке «Фактическое состояние кода» путь и каждый класс теста существует**; несуществующая ссылка делает сборку матрицы невозможной.
- Статус `IMPLEMENTED_AND_TESTED` присвоен только там, где найден тест, проверяющий именно заявленное поведение. Наличие класса теста само по себе не принималось: например, граф статусов документа (S06-02) получил `IMPLEMENTED_UNVERIFIED`, потому что прямого теста у него нет.
- **Обновление 2026-10-15 (этап R).** Строки, которые закрыты задачами этапа R, переведены в `IMPLEMENTED_AND_TESTED` только там, где тест проверяет заявленное поведение. Полный прогон бэкенда на локальной PostgreSQL 17 после исправлений: `./mvnw verify` — BUILD SUCCESS, 760 unit-тестов и 1109 интеграционных, 0 ошибок, ошибок исчерпания соединений нет; frontend: typecheck, lint и 317 тестов vitest зелёные. Первоначальный аудит (чтение кода, схемы и документов) тестов не запускал; его числа 1014 и 265 заменены этими.
- Наблюдения о работающем сервере (контейнер `bc-worker` unhealthy, 5 событий DEAD_LETTER, pgvector недоступен) получены чтением состояния сервера 2026-10-14. Исправления (проверка по свежести файла heartbeat, команда возврата событий в очередь) выложены, но на сервере после этого не проверены: у автора нет доступа к docker на сервере.

Строка со статусом `NOT_APPLICABLE` не является требованием (это правило процесса или согласованный пункт).
