## ЧЕГО ЭТИ ЧИСЛА НЕ ЗНАЧАТ — читать до использования

**Все 3277 запросов получили отказ.** Прогон шёл **без токена**, поэтому измерен **путь отклонения**
(фильтр безопасности), а **не** путь чтения списка счетов. Стенд сам это заметил и написал: «RESULT:
FAILURES PRESENT — the numbers are not a clean baseline».

**Что эти числа всё-таки показывают:** отклонение неаутентифицированного запроса занимает **p50 17 мс**,
максимум 60 мс, при четырёх одновременных вызывающих — то есть защита не является узким местом и не
создаёт очереди.

**Чего они не показывают:** ни одной цифры про чтение счетов, запись документа или полный путь приёма.

**Это не базовая линия.** Чтобы её получить, нужен запущенный экземпляр и действующий токен, и прогон
надо повторить **в том окружении, о котором собираются делать вывод** — измерение на ноутбуке против
тестовой базы не является ответом на вопрос «сколько выдержит продакшн». Именно поэтому здесь нет строки
с подписью «базовая линия»: её отсутствие честнее подписи под числами, которые ею не являются.

**Что нужно для настоящего прогона:**

```bash
# 1. экземпляр запущен и отвечает
curl -fsS http://127.0.0.1:8080/actuator/health
# 2. получен токен приёма или сессия пользователя
# 3. прогон с токеном
BASE_URL=http://127.0.0.1:8080 TOKEN=<token> CONCURRENCY=4 DURATION=60 \
  LABEL="<окружение>" ./run-load.sh
```

## Попытка прогона на рабочем пути (раунд 56) — НЕ ВЫПОЛНЕНА

**Путь приёма теперь существует:** в раунде 55 найден и закрыт пробел — у `IngestService` не было
HTTP-слоя вообще, и Desktop Bridge слал в несуществующий адрес. Теперь `POST /api/v1/documents:ingest`
работает, хеш вычисляется сервером, а машинный вызов освобождён от CSRF.

**Подготовка выполнена полностью:** создан арендатор, рабочая область и API-токен с областью
`documents:write` (хеш посчитан тем же SHA-256, которым его ищет сервис).

**Прогон не состоялся, потому что экземпляр не удалось запустить.** Приложение собрано, но **файл
`target/buerokratie-copilot-api.jar` недоступен для чтения**:

```
ls -1 target/                    → burokratie-copilot-api.jar        (в каталоге числится)
stat target/buerokratie-copilot-api.jar   → No such file or directory
cp target/buerokratie-copilot-api.jar /tmp/  → No such file or directory
java -jar target/buerokratie-copilot-api.jar → Unable to access jarfile
```

**Проверено тремя способами, и свежая пересборка (`mvnw package`, exit 0) воспроизводит то же самое.**
Это **условие окружения, а не кода**: каталог читается при листинге, а файлы в нём — нет.

**Чего в этом разделе поэтому НЕТ:** ни одной цифры про рабочий путь. **Строки с подписью «базовая
линия» здесь по-прежнему нет, и это правильное состояние отчёта** — отсутствие честнее подписи под
числами, которых не существует.

**Что нужно, чтобы прогон состоялся:** запущенный экземпляр (в окружении, где артефакт доступен) и
выполнение `BASE_URL=... TOKEN=<токен> ./run-load.sh` с набором приёма.
