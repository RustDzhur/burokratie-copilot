# tests/corpus — synthetic document corpus

Generated by [`scripts/quality/generate_corpus.py`](../../scripts/quality/generate_corpus.py).
Do not edit files here by hand: they are deterministic output of the seed and the
templates, and the manifest is the ground truth for the quality run.

```
tests/corpus/
├── documents/
│   ├── manifest.json          # all documents (dev + holdout), ground truth
│   ├── manifest-dev.json
│   ├── manifest-holdout.json
│   ├── dev/                   # 80 files: images + multi-page PDFs
│   └── holdout/               # 53 files: other providers/wording, not used for tuning
└── results/                   # JSON results of the last quality runs (evidence)
```

Regenerate everything:

```bash
python3 scripts/quality/generate_corpus.py --split all --clean
```

Run it through the pipeline and rebuild the report:

```bash
scripts/quality/run-corpus.sh
```

The generator needs Python 3 with Pillow, OpenCV and NumPy. The stand needs Tesseract with
`deu` language data; `rus` is optional and only used for the Russian experiment.

Each document entry carries `trueType`, `trueCategory`, `difficulty`, `condition`,
`expectedNumber`, `expectedDate`, `expectedAmount`, `expectedSupplier`, `expectedFields`
and `acceptableTypes`. See `scripts/quality/README.md` for the metric definitions.
